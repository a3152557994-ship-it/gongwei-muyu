## 五、红线（踩了会白跑）

1. **不写宗教词卖点**：不用"功德/祈福/许愿/香火/供奉/开光"，页面里已经有明确声明"不是宗教服务"。
2. **不做付费功能**：1 元是打赏，不是买功能；任何"付费解锁"都会把定位变成付费服务。
3. **收款码被封就换**：微信赞赏码被限制 → 换支付宝收款码；两个都被限制 → 页面先挂着，不算失败。
4. **不买量**：花 100 元以上买流量，这个实验就失去意义（要测的是自然传播）。
