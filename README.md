# 工位木鱼

敲一下，掉一点班味。打开网页就能敲，不用注册、不用登录、不用说话。

**在线试：** https://a3152557994-ship-it.github.io/gongwei-muyu/

## 它是什么

一个 24KB 的单页木鱼。点一下屏幕上的木鱼，它响一声，摸鱼值 +1。

- 没有任务、没有排行榜、没有聊天、没有好友
- 木鱼声是 **WebAudio 现场合成**的（噪声瞬态 + 三个衰减不同的正弦做腔体共鸣），不加载任何音频文件
- 整个站点零外部依赖，离线双击 `index.html` 也能玩

## 链式参数

在地址后面加 `?c=` 可以区分渠道：`?c=v2ex`、`?c=jike`、`?c=xhs`。
